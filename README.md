# Skill Estratégia Conteúdo Infinito

Skill para alunos do produto **Conteúdo Infinito** criarem uma estratégia de conteúdo prática para Instagram, produtos digitais ou serviços.

## Como usar

1. Abra o arquivo [`SKILL.md`](./SKILL.md).
2. Copie o link do arquivo ou o conteúdo completo.
3. Cole no ChatGPT e diga:

```text
Instale essa skill.
```

Depois use:

```text
Use a skill Estratégia Conteúdo Infinito e me entreviste para criar minha estratégia de conteúdo.
```

## O que ela faz

A skill faz um briefing obrigatório em sequência fixa e entrega um documento final chamado **Minha Estratégia de Conteúdo**, pronto para salvar no ChatGPT Work, em um Projeto ou no Google Drive.

Ela organiza:

- identidade
- Instagram
- público-alvo
- oferta
- promessa
- posicionamento
- tom de voz
- pilares de conteúdo
- objeções
- referências
- banco inicial de ideias
- rotina de conteúdo
- comandos prontos

## Observação

A sequência das perguntas foi mantida fixa para acompanhar as aulas do curso.
